Slapon
Description
Slapon is a C# application designed to provide robust annotation tools for images and screenshots. It allows users to capture screen regions, annotate with various tools, and save or copy the annotated images.

Features
Annotation Tools: Rectangle, Highlight, Line, Text, and Select.
Color Picker: Choose from common colors or use a custom color picker.
Screen Capture: Capture the screen or a selected region.
Image Manipulation: Resize, move, and edit annotations.
Clipboard Integration: Copy images with annotations directly to the clipboard.
Save Functionality: Save annotated images in PNG format.
Installation
To run Slapon, ensure you have the following prerequisites:

.NET Framework (version 4.7.2 or newer)
Clone the repository:

git clone https://github.com/nouxoid/Slapon.git
Navigate to the project directory and build the solution using Visual Studio or the .NET CLI:

bash
cd Slapon
dotnet build
Usage
Run the application.
Use the toolbar at the top to select an annotation tool.
Capture the screen or open an image to annotate.
Save or copy the annotated image as needed.
Dependencies
System.Drawing: Used for image manipulation and rendering.
Windows.Forms: Provides the GUI components.
